# Observa

Ground control station and flight-log analysis tool for Project Solaris — Qt/C++ GCS plus the Python analysis tool, in one repo.

Consumes the [NovaLink](https://github.com/baremetalaviator/NovaLink) protocol as a submodule under `protocol/`.

Part of Project Solaris: [Vanguard](https://github.com/baremetalaviator/Vanguard) (hardware) · [Nebula](https://github.com/baremetalaviator/Nebula) (firmware) · [NovaLink](https://github.com/baremetalaviator/NovaLink) (protocol)
